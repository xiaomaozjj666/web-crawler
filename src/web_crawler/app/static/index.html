任务概览
只填你自己的授权 Cookie。
URL 含这些关键词则跳过。已内置常见广告和验证服务关键词。

抓取范围

下载行为

默认会下载资源；勾上则只在清单里登记地址（省磁盘、对目标站压力小）
页面先用 headless Chromium 渲染再解析；适合 JS 单页站或拒绝纯 HTTP 的站点，渲染失败自动退回普通抓取

内容处理

字段规则与页面样本

样本保存在此任务中，每页最多 2 MiB，压缩后每次任务最多 16 MiB。删除任务时一并删除样本。
